## 重新拆分的真正小题阶梯（2026-11-05）

旧8档采用同一复杂题的预填比例，容易造成“只剩一步但仍需理解整张大题”的难度断层。默认学习入口现改为35项目各10个基础小步，共350个练习阶段。原来的8档及神龙10档作为保留记录的独立进阶路径，不会自动进入，也不把新增基础小题当作比赛等难训练。

纵横之间从2个可点位置里照着找1条线开始：换位置照点、自己遮住后找1条、增加可选位置、看着找2条、遮住找2条、两次各记1条、看着找3条、遮住找3条、两次记4条。最多只记4条线、7个位置、2组观察；全程无计时，遮住时机由学习者决定。其他模型只练极少元素的一种核心判断，避免在入门阶段出现完整星阵、22块滑块、200张线纹或27块二维码链。

每个小步连续独立完成两次才开放手动升一步，重复检查同一答案不累计；答错留在相同规模，可原题跟练。提示完成不记独立，已过关进度不会因退回重练丢失。只有全部10小步完成后，才出现自选的旧进阶课程入口。小题的重复练习不当作未见题测评。自动生成题可能重复基本情形，不以题号冒充不同节目原题。

完整备份升级v9，保留并接受v1–v8数据；新进度独立存于`curriculum.foundation`，不改写旧题面、分数、通过状态或笔记。新阶段与当前选择、观察状态、辅助状态均可恢复。运行`node foundation-tests.cjs`验证35模型、350阶段、7000组生成检查与实际UI状态机。

## 神龙摆尾的实现边界

操作分成“选长龙、折叠、六面核对”三步，避免把所有操作堆在一页。候选共用相同的直通/拐弯结构；在示例折法中，每条干扰候选仅替换一个面的二维码，其余五面一致，不能只看共有定位框。

每块在自身坐标系中有六个纹样面。旋转同时改变后续方向与图案朝向，引擎检查落位的边界、格点重叠、完整性和六面投影。搜索全部合法折法后，每套只有一个匹配候选；不强制使用参考折法，也不声称折法唯一。

自由练习可保持形状切换候选，方便观察差异；竞速换另一条候选会清空折叠进度，防止复用形状快速试交。候选排除、转向、撤回、重置、提交、提示与复盘进入完整存档。

正式目标和干扰采用真实Version 1二维码编码，共420个符号经独立解码器检查。对JS引擎结果反向坐标重采样后，72个目标面再次成功解码。[21×21模块定义见DENSO WAVE](https://www.qrcode.com/en/about/version.html)。生成使用[python-qrcode](https://github.com/lincolnloop/python-qrcode)；成品网页无需安装依赖或联网调用。二维码只编码题号文本，不含外部跳转。

**六面逐像素匹配不等同于摄像头扫码。** 二维码纠错可能让有差异的图案仍被解码；本版要求图案精确一致。分块辅助线可关闭。模型只检查落位，不检查实体的转动过程，因此是原创仿真，不是节目完整机械复刻或等难认证。

8档依次为：一条规则判断、只补一个动作、小题半扶助、小题从头完成、大题约80%参考动作已预填、大题约50%预填、大题约20%预填、大题从头完成。数字是参考过程预填比例，不是科学难度量表；有些项目沿用相同盘面尺寸，用减少预填来分级，不声称所有档位都有不同尺寸。风车小题另按无旋转、单卡旋转、多卡旋转渐进；数织/异或/爆破复合题的只补一步关，只检查第一阶段，后续才组合完整流程。

每档有项目专用规则、小例子、分步参考过程、当前状态提示和“接回参考过程”。可撤回自己的操作，重置回本档预填起点。例子或提示算辅助，辅助完成后独立重做通过才能升档；已经通过的历史与笔记保留。该“独立”表示当次未展开辅助，不是未见题资格。正式题库仍区分首次、辅助、复练、中断。

记忆题先分组观察再遮住作答；可提前结束，重新观察算辅助。观察中刷新、切后台、导入恢复会结束展示并标记中断，重做后重新观察。学习例子可展开全部观察资料。

8档通过才可新开相应正式题；既有正式训练草稿保留。大题教学与例子使用的题号计入“已见”，进入正式选题会优先避开这些题。31个项目解锁的是已有核心分解题库，只有原4项是完整专项仿真，仍不冒充节目机械装置或官方等难。

## 找第一步、解释选择与判断下一步

35个项目各有一门“老师带你推理”小课，共106个引导判断。小课先给具体小盘/数值，再让学习者做判断；选择后才展开依据、错误分支与下一步检查。思路课放在首档规则测验之前，不用先翻到一份答案才能看到方法。课程步数、选择和展开状态进入完整备份v8，v1–v7旧记录可恢复。

数阵迷踪使用 `[2,6,15;7,14,35]` 小盘：从2的邻居6/7算公共因数，推出单出口端点；从6比较15与14，并分别演示走14后两条死路。实际小题与大题则根据当前路径列出相邻格、公因数、是否用过、剩余连通性与多余端点。没有单出口或唯一候选时明确保留试探，不把启发式说成必选。

分步例子和“带我判断下一步”改为“先看哪里 → 为什么这样判断 → 下一步怎么判断”，并列出实际约束计算。各项目分别使用线和、候选距离/奇偶性、镜像差异、模九余量、闪烁奇偶、分压区间、路口等待、体素空区、视域角与遮挡、坐标变换等依据。联动表盘可通过首行枚举与模12约束推导出一组可行方案并核验，不强制唯一。视觉识别讲解区分辅助定位与推导证明，局部合法不会被表述为全题已解。

记忆资料只在观察/辅助讲解中展开；输入类题可点“按当前输入刷新推理”。查看老师讲解会标辅助，独立重做时收起讲解。偏离参考过程的合法数阵路线仍有当前状态分析，无须先回参考路线。掌纹叠影判分同步改为复核实际单图并集，接受组成数量一致的视觉等价组合。
