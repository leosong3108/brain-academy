# 脑力研习室

运行中的网站：https://leosong3108.github.io/brain-academy/#guide

面向《最强大脑》备赛的个人训练站。默认进入学习路线。四个入口：开始学习、专项训练、基础练习、我的档案。原基础练习、题库、测评与错题本继续保留。

## 学习路线与进阶

三个专项各有“读规则 → 看例子 → 跟着练 → 完整训练”四步课堂。课程明确目标、允许的操作、完成条件和常见误解；例题共11帧，可以前进与回看。

- 数阵迷踪：4格逐步路径例子；6格点击跟练，错误连接即时解释。
- 数字迷途：3×3的1–9逐格填入例子；另一道3×3跟练，检查重复、遗漏和连续数字邻接。
- 闪光迷图：3×3、2块拼片的叠色例子，演示7+5=12、减9得3；跟练支持选片与坐标摆放，检查全部格。

小题草稿、课程位置、跟练完成、提示和尝试次数自动保存。通过跟练后进入选题页，先独立完成不限时整题，再用新题竞速；不会自动启动计时。

首页指出下一步课程或未完成训练。每周目标可设3/5/7场，可选训练重点或按有效新题记录自动安排。档案显示实际独立完成、新题完成、同专项同设置用时和复盘，不给“脑王等级”，不承诺训练场数等于晋级能力。当前只有3个专项，尚未覆盖整季或所有参赛能力。

九类基础方法课都有实际渲染的例题与可展开讲解。基础练习另提供题库、错题复习和站内六维测评。

## 存档与隐私

- 浏览器本地自动保存，无账号、无服务器、无云同步。
- 同一站点、同一浏览器继续练习；清缓存/换浏览器可能失去记录，请定期导出。
- 完整JSON备份v3包含课程进度、小题草稿、每周计划、基础记录、比赛草稿、操作轨迹、提示、罚时和复盘笔记。导入先检查完整性和规则一致性，再预览确认。
- 接受原版v1/v2备份并迁移；旧版本网站不支持v3备份，请使用当前版恢复。
- 保留上一份可读本地副本。多页面更新冲突会阻止覆盖并提示导出。
- 本库不包含用户的私人初测成绩、上传资料或训练存档。个人分数只有主动导入后才留在本机。
- 这是本机训练工具，参考解随离线源码提供，没有远程防作弊能力。资格标记用于自我记录。
