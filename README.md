# 脑力研习室

学习方法、分级练习、六维测评与本机训练存档。

**网站：<https://leosong3108.github.io/brain-academy/>**

## 功能

- 9节方法课，支持笔记与学习进度。
- 9种题型、3档难度、每档40道固定编号生成题，共1,080道。
- 基础六维测评：12题、18分钟，提交后统一复盘。
- 错因记录，按1天、3天、7天安排间隔复习。
- 保存未提交输入、路径、滑块盘面和训练进度；支持完整JSON备份恢复。

题库为新编基础练习与节目规则改编，非官方真题或资格测试。没有智力常模或“脑王等级”。

## 数据与隐私

网站和源码可公开访问，源码不包含个人初测成绩、对话记录或训练备份。

每个人的作答、笔记、错题和进度只保存在各自浏览器的本地存储中；没有云同步。换设备、换浏览器或清理数据前，请在“训练档案”中导出完整备份，再在新设备手动恢复。

同一浏览器的`github.io`网站可能共享同一来源的存储。建议只在可信设备和可信的GitHub Pages页面中使用，及时备份。

从其他网址迁移时，不会自动读到旧站记录。本站v1完整存档可以导入；更早的审查版v2汇总格式不支持自动转换。

## 开发与验证

不需要安装第三方依赖。使用Python生成单文件网站：

```sh
python3 build.py
node tests.cjs
python3 -m http.server 8000 --bind 127.0.0.1
```

浏览器打开`http://127.0.0.1:8000/`。

- `engine.js`：题库、生成规则、判分。
- `content.js`：方法课。
- `store.js`：本机存档、备份校验与恢复。
- `app.js`：界面与训练流程。
- `style.css`：响应式样式。
- `build.py`：将上述源码打包到`index.html`。
- `tests.cjs`：无外部依赖的模型验证，包括全部题目答案和120道滑块的独立最短距离检查。

修改源码后，请重新生成`index.html`并通过测试，再一起推送。GitHub Pages从`main`分支根目录发布；`.nojekyll`禁用不需要的Jekyll处理。

## 使用边界

难度和训练目标为本站设定；题型与难度不同的分数不要横向等同。中断的测评不计有效首次基线，重做答对一次也不代表掌握。手机尺寸布局已检查，真实iOS Safari与软键盘体验仍需真机验证。
