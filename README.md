## 神龙摆尾的实现边界

操作分成“选长龙、折叠、六面核对”三步，避免把所有操作堆在一页。候选共用相同的直通/拐弯结构；在示例折法中，每条干扰候选仅替换一个面的二维码，其余五面一致，不能只看共有定位框。

每块在自身坐标系中有六个纹样面。旋转同时改变后续方向与图案朝向，引擎检查落位的边界、格点重叠、完整性和六面投影。搜索全部合法折法后，每套只有一个匹配候选；不强制使用参考折法，也不声称折法唯一。

自由练习可保持形状切换候选，方便观察差异；竞速换另一条候选会清空折叠进度，防止复用形状快速试交。候选排除、转向、撤回、重置、提交、提示与复盘进入完整存档。

正式目标和干扰采用真实Version 1二维码编码，共420个符号经独立解码器检查。对JS引擎结果反向坐标重采样后，72个目标面再次成功解码。[21×21模块定义见DENSO WAVE](https://www.qrcode.com/en/about/version.html)。生成使用[python-qrcode](https://github.com/lincolnloop/python-qrcode)；成品网页无需安装依赖或联网调用。二维码只编码题号文本，不含外部跳转。

**六面逐像素匹配不等同于摄像头扫码。** 二维码纠错可能让有差异的图案仍被解码；本版要求图案精确一致。分块辅助线可关闭。模型只检查落位，不检查实体的转动过程，因此是原创仿真，不是节目完整机械复刻或等难认证。

## 神龙摆尾：从零到完整专项的10档课程

入口保留 `#course-dragon`，也可从首页“从零开始／继续分级学习”进入。

1. 认X/Y/Z方向，只判断一个相邻落点。
2. 只练一次转弯，从2块到第3块。
3. 拼4块下层，不看图案。
4. 拼8块立方体，仅检查形状。
5. 已给4块，只核对前面图案。
6. 固定正确候选，8块核对六面。
7. 8块，自己在2条候选中筛选。
8. 27块已给21块，补最后6块并核对六面。
9. 27块已给9块，补18块。
10. 正确候选已给出，从头折27块。

随后解锁原有30候选、27块完整选题，默认先不限时。未通过学习关的新开题会返回课程；已有正式训练草稿继续保留。每关独立通过才能升档，看例子、精确提示、错块定位或接回参考路线均标辅助；辅助完成后可重置当次重新练，历史通过与笔记保留。独立通过仅指本关未打开辅助，不是未见新题或参赛资格。

全部10档真实调用同一折叠与投影模型。单面/形状关只检查该关约束；六面关仍逐像素判定。27块分步例子使用第1题，跟练使用第2题，观看后标记见过，正式选题默认选择其余未见题。小题按同题巩固设计，不宣称迁移验证。
