# 脑力研习室

运行中的网站：https://leosong3108.github.io/brain-academy/#arena

面向《最强大脑》备赛的个人训练站。默认进入比赛专项，基础热身、学习课程、题库、测评与错题本继续保留。

## 基础内容

9种基础题型，每类3档、每档40道，共1,080道固定编号生成题。方法课、18分钟站内测评、错题间隔复习、笔记和个人档案。基础成绩不与比赛专项混算，不换算IQ。

## 存档与隐私

- 浏览器本地自动保存，无账号、无服务器、无云同步。
- 同一站点、同一浏览器继续练习；清缓存/换浏览器可能失去记录，请定期导出。
- 完整JSON备份v2包含基础记录、比赛草稿、操作轨迹、提示、罚时和复盘笔记。导入先检查完整性和规则一致性，再预览确认。
- 接受原版v1备份并迁移；旧版本网站不支持v2备份，请使用当前版恢复。
- 保留上一份可读本地副本。多页面更新冲突会阻止覆盖并提示导出。
- 本库不包含用户的私人初测成绩、上传资料或训练存档。个人分数只有主动导入后才留在本机。
- 这是本机训练工具，参考解随离线源码提供，没有远程防作弊能力。资格标记用于自我记录。

## 运行与验证

直接打开 `index.html` 或使用任意静态服务器。无需安装依赖。

源文件改动后运行：

```sh
python3 build.py
node tests.cjs
node arena-tests.cjs
```

构建输出为单文件 `index.html`，GitHub Pages从main根目录发布。

验证：基础2,904项断言；比赛692项断言，36题参考解、操作回放、撤回、计时罚时、导入迁移和错误备份拒绝；12道数字迷途用不同于生成器的分段路径枚举+互斥覆盖算法再次证明唯一解。浏览器实测三专项完整作答、错误罚时、刷新恢复、完整备份恢复，以及390/320像素窄屏。上述验证证明实现行为，不等于节目难度认证。
