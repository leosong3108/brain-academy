# 脑力研习室

[打开学习路线](https://leosong3108.github.io/brain-academy/#guide) · [神龙摆尾教程](https://leosong3108.github.io/brain-academy/#course-dragon)

面向《最强大脑》备赛的个人训练站。四个入口：开始学习、专项训练、基础练习、我的档案。所有题目为原创训练题，没有官方等难认证、选手常模或晋级分数线，不计算“脑王等级”。当前只覆盖4个专项，不能代表全面参赛能力。

## 先学会，再独立训练

四个专项都有“读规则 → 看例子 → 跟着练 → 完整训练”的课堂，共16帧可前进与回看的例题。

- 数阵迷踪：4格逐步例子、6格点击跟练；错误连接即时解释。
- 数字迷途：3×3的1–9填数例子与另一道跟练；检查重复、遗漏、邻接。
- 闪光迷图：3×3、2块拼片的模九叠色例子与跟练；支持选片和坐标摆放。
- 神龙摆尾：5步空间折叠例子、2候选8块跟练；分层坐标、旋转尾块、取回一块、六面核对。教学纹样14×14，不可扫码。

草稿、课程位置、提示、尝试次数与跟练完成自动保存。进入完整训练先选题，不会立即计时。建议先独立完成不限时整题，再用没做过的新题竞速；每次回放操作，记录卡点并验证改进。

每周目标可设3/5/7场，可选重点或按有效新题记录自动安排。档案显示实际完成、首次竞速、同专项同设置用时和复盘；不同题目仍可能有难度差异，用时不是能力认证。

## 神龙摆尾的实现边界

操作分成“选长龙、折叠、六面核对”三步，避免把所有操作堆在一页。候选共用相同的直通/拐弯结构；在示例折法中，每条干扰候选仅替换一个面的二维码，其余五面一致，不能只看共有定位框。

每块在自身坐标系中有六个纹样面。旋转同时改变后续方向与图案朝向，引擎检查落位的边界、格点重叠、完整性和六面投影。搜索全部合法折法后，每套只有一个匹配候选；不强制使用参考折法，也不声称折法唯一。

自由练习可保持形状切换候选，方便观察差异；竞速换另一条候选会清空折叠进度，防止复用形状快速试交。候选排除、转向、撤回、重置、提交、提示与复盘进入完整存档。

正式目标和干扰采用真实Version 1二维码编码，共420个符号经独立解码器检查。对JS引擎结果反向坐标重采样后，72个目标面再次成功解码。[21×21模块定义见DENSO WAVE](https://www.qrcode.com/en/about/version.html)。生成使用[python-qrcode](https://github.com/lincolnloop/python-qrcode)；成品网页无需安装依赖或联网调用。二维码只编码题号文本，不含外部跳转。

**六面逐像素匹配不等同于摄像头扫码。** 二维码纠错可能让有差异的图案仍被解码；本版要求图案精确一致。分块辅助线可关闭。模型只检查落位，不检查实体的转动过程，因此是原创仿真，不是节目完整机械复刻或等难认证。

- 本库不含用户初测成绩、上传的私人资料或个人训练存档。手动导入的个人分数只在本机。
- 参考解包含在离线源码中，没有远程防作弊。资格标记用于自我记录。
